# TabArcade

TabArcade is a static, English-language portal of free browser games aimed at
"unblocked games / classroom games" search demand. Every game loads in a normal
browser tab — no downloads, no installs, no sign-ups — and works on
Chromebooks, laptops and phones.

**Live site:** https://honru09.github.io/tab-arcade/

Built with [Astro](https://astro.build) (fully static output), deployed to
GitHub Pages by GitHub Actions on every push to `main`.

## How the game catalog is generated

Games come from licensed syndication feeds — never scraped or ripped:

- **Primary:** GameDistribution catalog API (`catalog.api.gamedistribution.com`)
- **Filler:** GameMonetize feed (`gamemonetize.com/feed.php`)

`src/data/games.json` is a generated file. Regenerate it any time with:

```bash
npm run fetch-games        # = node scripts/fetch-games.mjs
```

The script (no API keys needed — both feeds are public):

1. Pulls up to 800 GameDistribution games (paginated) and the 2,000-game
   GameMonetize feed.
2. Tries to match the priority launch titles from `research/KEYWORDS.md`
   by name. Most famous titles (Slope, Retro Bowl, 1v1.LOL…) are licensed
   exclusives of other portals and are **not** in syndication feeds — the
   script records near-name matches only (e.g. *Snow Rider Neo*) and never
   labels a page with a game it does not actually embed.
3. Fills the catalog to ~90 games with category quotas matching the SEO plan:
   racing/drifting, runners (Agility), sports, .io, puzzle/math, shooter,
   simulation.
4. Normalizes each game: title, slug, embed URL, thumbnail (hotlinked from
   the feed CDN), categories, tags, lightly rewritten description, cleaned
   instructions.

### GameDistribution revenue attribution

GD embed URLs carry `?gd_sdk_referrer_url=<this game's page URL>` (added by
the fetch script, using the site's base URL). Revenue is credited to the
publisher account that has the serving domain registered — embeds play fine
anonymously, but register the domain in a GameDistribution publisher account
before promoting the site, or plays earn nothing.

## Adding games

1. Run `npm run fetch-games` to refresh the catalog, **or** hand-add an entry
   to `src/data/games.json` with the same shape as the existing entries
   (`title`, unique `slug`, `embedUrl`, `pageUrl`, `thumb`, `categories`,
   `tags`, `description`, `instructions`, `width`, `height`, `mobile`,
   `featured`, `source`).
2. `npm run build` — the game page, grids, related-games rails and the sitemap
   are all generated from the data file. There is no per-game code to write.
3. Push to `main` — GitHub Actions rebuilds and redeploys automatically.

To change which games are "featured" on the home page, edit the `featured`
flags in `src/data/games.json` (first 12 selected games are featured by
default when the data is regenerated).

## Site structure

| Path | What |
|---|---|
| `src/pages/index.astro` | Home: hero, featured grid, category sections |
| `src/pages/games/[slug].astro` | One page per game: playable iframe + fullscreen button, About, How to Play, FAQ (template-generated), related games, VideoGame + FAQPage + Breadcrumb JSON-LD |
| `src/pages/[hub].astro` | Hub pages for the 10 classroom/math/hub keywords (copy in `src/data/hubs.mjs`, each with an original intro) |
| `src/lib/games.mjs` | Shelves (category filters), related-games scoring, FAQ generator, base-path URL helper |
| `src/layouts/Base.astro` | Shared layout: title/meta/canonical/OG tags, nav, global styles |
| `public/robots.txt` | Points crawlers at the sitemap |
| Sitemap | Auto-generated by `@astrojs/sitemap` at `/sitemap-index.xml` |

Positioning rule (from the keyword research): always phrase the site as
"free browser games — no downloads, works on Chromebooks". Never use
"bypass school filters" framing.

## Local development

```bash
npm install
npm run dev        # local dev server
npm run build      # static build into dist/
npm run preview    # preview the built site
```

## Deploy flow

Push to `main` → `.github/workflows/deploy.yml` runs the official Astro
GitHub Action (build) → `actions/deploy-pages` publishes to GitHub Pages.
The site is a GitHub Pages *project* site, so `astro.config.mjs` sets
`site: 'https://honru09.github.io'` and `base: '/tab-arcade'`; all internal
links go through the `u()` helper in `src/lib/games.mjs` so the base path is
applied everywhere. If the site moves to a custom domain, update `site`,
`base`, the `SITE_BASE` constant in `scripts/fetch-games.mjs`, regenerate
the data (embed referrer URLs change), and rebuild.
